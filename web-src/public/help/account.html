Conta

Acesso e recuperação

Use a conta deste site. Na tela de entrada, escolha Entrar com WordPress, Esqueci minha senha ou Criar conta quando o site permitir. Se você já tiver entrado no site, o Code abre com a mesma conta.

Configurar Minha IA

Escolha um provedor, salve sua chave, escolha um modelo e teste a resposta. O site faz a consulta ao provedor escolhido. O consumo vai para sua conta no provedor. Seu código e os resultados de teste podem fazer parte da consulta.

Chaves dos provedores

Abra a página indicada na Conta para criar uma chave. Cole a chave inteira, salve e teste. Você pode trocar ou remover a chave na mesma seção. O WordPress guarda a chave de forma criptografada.

Google Gemini

Crie uma chave de API no Google AI Studio, selecione Google Gemini e salve a chave. Depois escolha um modelo do catálogo.

Escolher modelo

Abra o catálogo e escolha um modelo disponível para sua conta. Se houver erro de acesso, confira o provedor, o modelo e os limites na sua conta do provedor.

Raciocínio

Use o padrão do modelo quando estiver em dúvida. O nível mais alto pode demorar mais. O site mostra as opções aceitas por cada modelo.

Testar resposta

A ação Testar resposta usa a configuração salva e envia uma consulta curta. O resultado aparece junto ao botão de teste.

Executar no meu computador

Na aba Executor, baixe o ZIP e siga o guia incluído. Depois cole o código de conexão completo. Se reiniciar o programa, use o novo código.

Python e JavaScript também funcionam no navegador. O executor local roda programas com as permissões da sua conta. Execute apenas código confiável.

Exportar, apagar dados e sair

Na aba Meus dados, exporte seu arquivo JSON ou solicite a exclusão dos seus dados no Code. Para excluir seus dados, use a senha da conta WordPress e digite APAGAR. Se você criou eventos, exclua-os primeiro. A opção Sair encerra a sessão neste site WordPress.
